# extension.js

`extension.js` is the main entry point for the SPIKE Prime C VS Code extension. VS Code loads this file because `package.json` sets `"main": "./extension.js"`.

## What It Does

- Creates the `SPIKE Prime C` output channel.
- Adds status bar actions for hub selection, build, and run.
- Registers extension commands declared in `package.json`.
- Registers the SPIKE Prime activity bar tree views.
- Creates new projects by copying files from `templates/basic-c`.
- Runs build and upload commands from the active workspace folder.
- Provides SPIKE-RT configuration helpers for common local and Docker-based workflows.

## Main Command Flow

- `activate(context)`: initializes UI items, commands, output channel, and tree views.
- `newProject()`: prompts for a project folder name and copies the starter template.
- `build()`: runs the configured `spikePrimeC.makeCommand`.
- `upload()`: runs the configured `spikePrimeC.uploadCommand`, optionally showing DFU instructions first.
- `buildAndRun()`: builds first, then uploads only if the build succeeds.
- `selectHub()`: updates the hub status bar label for USB or manual mode.
- `configureSpikeRt()`: writes workspace settings for either Docker-based SPIKE-RT or simple local make usage.
- `openSpikeRtBuild()`: lets the user open an existing SPIKE-RT generated build folder.

## Helper Areas

- Command execution is handled by `runCommand`, `runCommandInTerminal`, and `expandCommand`.
- User-friendly build failure hints are generated by `friendlyHints`.
- Workspace and configuration access is handled by `getWorkspaceRoot` and `getConfig`.
- Template copying is handled by `copyTemplate`.
- Static activity bar views are provided by `StaticTreeProvider` and `TreeItem`.

## Notes for Changes

When adding a new command, update both `extension.js` and `package.json`:

1. Add the command registration in `activate`.
2. Add the command contribution in `package.json`.
3. Add an activation event if the command should activate the extension.
4. Update user-facing documentation if the command changes the workflow.

The extension currently assumes the first open workspace folder is the active SPIKE Prime project.
